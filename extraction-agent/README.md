# Extraction Agent

This folder contains the Claude-based extraction agent that parses meeting transcripts and extracts action items.

## Contents

- `agent.py` — Main extraction agent logic
- `prompts.md` — System prompts and extraction rules
- `test_transcripts/` — Sample transcripts for testing

## Usage

The agent takes a meeting transcript and returns structured action items with descriptions, owners, due dates, and status.

See `../requirements.md` for the full specification.
